# MQTT 学习路线图

> 系统学习 MQTT，深度对标"完整读完一本书"；通用学习与设备接入各占一半。
> 没有单一教材：大纲由 OASIS MQTT 5.0 规范、HiveMQ MQTT Essentials、EMQX 文档、Eclipse Sparkplug 规范等交叉合并而成，详见本地大纲文件。
> 学习方式：每个模块开始前先给三层知识大纲（★ 核心必会 / ☆ 高频重点 / ○ 了解即可）→ 讨论 → 输出笔记。核心专题配实验，关键机制配可交互图解。
> 版本基线：MQTT 5.0 为主，3.1.1 差异单独标注。

## 规模与路径

共 **12 个模块、51 个专题**，其中 ★ 28 个。第一遍走 ★ 主干，☆ 第二遍补齐，○ 按需浏览。

**例外（2026-10-12 确认）**：模块一的 4 个专题第一遍全部按顺序学——专题 4 是后面所有实验的环境，专题 1 能建立直觉；专题 1、3 讲得紧凑些。从模块二开始严格只走 ★。

第一遍路径：1, 2, 3, 4，然后 ★ 主干 5, 6, 7, 8, 10, 11, 12, 14, 15, 17, 19, 22, 23, 24, 25, 26, 27, 28, 31, 32, 39, 41, 43, 46, 47, 50, 51（共 31 个）。

实验与案例统一用一条贯穿场景：计量设备上报数据、接收指令、断网补传（举例，可替换）。
