# 主流 Broker 对比与源码入门

> 专题 29 · 模块六 · ☆ 高频重点
> 第二遍 · 低优先级 8 个合讲 · 简述；EMQX 5.9 起 BSL 许可已在专题 3 核实，其余许可证与版本未本次核实；无实验

## 1. 核心概念

| broker | 定位 | 备注 |
|---|---|---|
| Mosquitto | 轻量、单机、单线程，边缘与中小规模 | 本次学习全程使用（26） |
| EMQX | 大规模集群，功能丰富（规则引擎、QUIC 等） | 5.9 起 BSL，商用前核对 |
| HiveMQ | 企业级集群，Java 生态 | 社区版与商业版 |
| NanoMQ | 极轻量，面向边缘网关 | 与 EMQX 同一公司 |
| VerneMQ | Erlang 实现的集群 broker | |

**读源码思路**：选一个 broker，跟踪一条 PUBLISH 从进来到发出的路径，对照 26 的流水线（接收 → 解码 → 鉴权 → 路由 → 入队 → 发送）。Mosquitto 用 C、代码量较小，适合入门。

**对方案**：选型参考；50 已给"边缘 Mosquitto、大规模集群 broker"的建议。读源码属深入兴趣，非写方案必需。

## 2. 易混淆 / 易错点

| 错误理解 | 正确理解 |
|---|---|
| 功能最多的 broker 最好 | 按规模、运维能力、许可证、生态选 |
| 开源就能随便商用 | 许可证各不相同，EMQX 5.9 起为 BSL |
