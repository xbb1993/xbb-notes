# MQTT over QUIC

> 专题 35 · 模块八 · ○ 了解即可
> 第二遍 · 低优先级 8 个合讲 · 简述；EMQX 官方文档已核实（默认关闭、示例 UDP 端口 14567、客户端 SDK）；文档未说明是否标准化；无实验

## 1. 核心概念

- **是什么**：QUIC 是基于 UDP 的新传输协议（HTTP/3 使用），重连更快、网络切换时连接不易断、一条连接内多路数据互不阻塞。MQTT 跑在 QUIC 上可改善移动网络表现。
- **现状**：EMQX 5.0 起支持，**默认关闭**，示例端口 UDP 14567；客户端需专用 SDK（如 NanoSDK），QUIC 不通可退回 TCP/TLS；NanoMQ 可把传统 MQTT 设备经 QUIC 桥接到 EMQX。更像 EMQX 生态的扩展，非 MQTT 规范一部分。
- **对方案**：低。电表模组和库普遍不支持（44），许多现场网络对 UDP 不友好。

## 2. 易混淆 / 易错点

| 错误理解 | 正确理解 |
|---|---|
| QUIC 是 MQTT 的标准传输 | 目前主要是 EMQX 生态的扩展 |
| 开了 QUIC 所有客户端都受益 | 需专用 SDK |
