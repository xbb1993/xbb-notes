# MQTT-SN、CoAP 与多协议网关

> 专题 36 · 模块八 · ○ 了解即可
> 第二遍 · 低优先级 8 个合讲 · 简述；MQTT-SN 2.0：搜索可见 OASIS 小组 2025 年 10 月的工作草案，是否正式发布未核实；无实验

## 1. 核心概念

- **MQTT-SN**：为不走 TCP 的极小设备（传感器网络、Zigbee 等无线网络）设计的 MQTT 变体；主题用短编号代替、报文更小，经网关转为普通 MQTT。业界长期使用较早的 1.2 版；OASIS 小组在推进 2.0。
- **CoAP**：面向受限设备、类似 HTTP 请求-响应风格的协议，跑在 UDP 上。
- **多协议网关**：把这些协议翻译成 MQTT，思路同 40 的 Modbus 网关。
- **对方案**：低。电表多为市电供电、能跑 TCP；将来接入电池供电无线传感器时再看。

## 2. 易混淆 / 易错点

| 错误理解 | 正确理解 |
|---|---|
| MQTT-SN 就是 MQTT 的小号版本，可直连 broker | 一般需要网关转换 |
| CoAP 也是发布订阅 | 是请求-响应风格 |

## 3. 与其他章节的关联

## 4. 诊断实践

接入无线传感器时评估：网络类型（是否有 TCP/IP）、供电方式、网关是否支持 MQTT-SN/CoAP 转换。
