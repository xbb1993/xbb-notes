# 统一命名空间（UNS）与数据建模

> 专题 38 · 模块九 · ☆ 高频重点
> 第二遍 · 低优先级 8 个合讲 · 简述；无实验

## 1. 核心概念

- **是什么**：Unified Namespace，用一棵主题树按"企业 / 工厂 / 车间 / 产线 / 设备"层级表达整个企业的实时数据；各系统往树上发布、从树上订阅，而不是两两对接。常与 Sparkplug（37）一起提。
- **对方案**：中低。50 的 `em/v1/{租户}/{设备}/...` 本身就是小型统一命名空间。若客户要求接入其工厂 UNS，按客户层级规范在出口做主题映射（类似 33 的桥接加前缀）。

## 2. 易混淆 / 易错点

| 错误理解 | 正确理解 |
|---|---|
| UNS 是一种协议或产品 | 是一种数据组织思想 |
| 接入 UNS 要改设备主题 | 可在出口映射，内部保持自有规划 |

## 3. 与其他章节的关联

主题设计（8、27）、Sparkplug（37）、桥接前缀映射（33）、方案主题规划（50）。

## 4. 诊断实践

客户要求接入 UNS 时：取得其层级规范 → 在桥接或出口服务做主题映射 → 核对权限与数据范围。
