# MySQL 学习路线图

> 没有固定教材：大纲由《高性能 MySQL》第 3/4 版、MySQL 官方手册、《MySQL 技术内幕：InnoDB 存储引擎》、《MySQL 实战 45 讲》交叉合并而成。
> 版本基线 **MySQL 8.0 / 8.4 LTS（InnoDB）**，与 5.7 有差异处会单独标注。
> 学习方式：每个模块开始前先给三层知识大纲（★ 核心必会 / ☆ 高频重点 / ○ 了解即可）→ 讨论 → 输出笔记。核心专题配实验与“诊断实践”，关键机制配可交互图解。

## 三条贯穿主线

```
A 性能主线（数据访问路径）
  SQL → 优化器 → 执行计划 → 索引 → 页 → Buffer Pool → 磁盘

B 一致性 / 可靠性主线
  事务 → MVCC → undo → 锁 → redo → binlog → 崩溃恢复 → 复制

C 诊断主线
  问题 → 现象 → 指标 → SQL → EXPLAIN → 锁 → I/O / CPU / 内存 → 定位 → 优化 → 验证
```

每个专题都回答一个问题：它在这三条线里处于什么位置，出问题时从哪里观察。
