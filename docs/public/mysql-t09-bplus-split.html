B+ 树插入与页分裂

MySQL 专题 9 配套图解。为便于观察，每页最多放 4 条记录（真实 InnoDB 中一个 16KB 叶子页可放几十到几百行）。分裂规则按 InnoDB 的思路简化：新记录插在页的末尾时，只开一个新页放新记录、原页保持满；插在中间时，对半搬移。

建议先“重置 → 批量顺序 → 连续插入 20 个”，记下统计；再“重置 → 批量随机 → 连续插入 20 个”，对比两次的页数、填充率和叶子链的物理连续性。

树结构

非叶子页（记录 = 子页最小键 → 子页号） 叶子页（存数据行） 本步新分配的页 本步被分裂的页 本步插入的记录 页框下方细条 = 填充率；R = 根页（页号固定不变）；P1、P2… 为叶子段中的物理页号，N1、N2… 为非叶子段中的物理页号（每个索引的叶子与非叶子分属两个段，各自按分配顺序编号）

叶子链（按主键顺序，从左到右）

绿色箭头：下一页在叶子段中的物理页号正好 +1，范围扫描时是顺序读；红色箭头：物理上跳到别处，范围扫描变成随机读。
