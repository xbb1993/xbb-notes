总结：三种读异常在各隔离级别下是否会发生（InnoDB，普通 SELECT）

隔离级别脏读不可重复读幻读（普通 SELECT）普通 SELECT 读什么
READ UNCOMMITTED会会会最新数据，包括别人没提交的
READ COMMITTED不会会会每条语句开始时已提交的数据（每次重新拍照）
REPEATABLE READ不会不会不会事务内第一次读时拍下的照片，整个事务一直用它
SERIALIZABLE不会不会不会关闭自动提交时，普通 SELECT 自动变成加共享锁的读

RR 一栏的“幻读不会”只针对普通 SELECT（快照读）。加锁读（FOR UPDATE）、UPDATE、DELETE 读的是最新数据（当前读），场景 ③ 展示了它们能看到别人新插入并提交的行；InnoDB 在 RR 下用间隙锁阻止“加锁读之后”再被插入，见专题 26。
