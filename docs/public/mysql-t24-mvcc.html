判断规则（changes_visible）

版本的 trx_id 记为 id： 1. id == 创建者 ID → 可见（自己写的） 2. id < 低水位 → 可见（拍照前就提交了） 3. id >= 高水位 → 不可见（拍照后才开始） 4. id 在活跃名单 m_ids 中 → 不可见（拍照时还没提交） 5. 否则 → 可见（拍照前已提交） 不可见 → 沿回滚指针找上一个版本，重复判断
