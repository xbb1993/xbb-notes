两阶段提交与崩溃点

MySQL 专题 32、33 配套。一个事务提交时要写两份日志：InnoDB 的 redo log 和 Server 层的 binlog（复制与时间点恢复用它）。点两步之间的 ⚡，假设 MySQL 在那一刻崩溃，看重启后主库数据和 binlog（也就是从库会收到的内容）是否一致。默认配置“双 1”：innodb_flush_log_at_trx_commit=1、sync_binlog=1。

提交方式

事务：UPDATE t_acct SET balance = balance - 100 WHERE id = 1（余额 1000 → 900）。点击任意 ⚡ 选择崩溃时刻。
