# Redis 深入学习

> 依据：《Redis设计与实现》（黄健宏）  
> 目标：从“会用”到“懂原理”，服务于架构师能力建设；讲究实用，不为应试堆砌纯理论。

## 学习方式

每个章节固定三步：**知识大纲（核心必会 / 高频重点 / 了解即可）→ 充分讨论 → 输出正式笔记**。  
每篇笔记固定包含四部分：**核心概念、易混淆/易错点、与其他章节的关联、复习 Checklist**。

## 学习顺序

书中原始顺序是：数据结构与对象 → 单机数据库 → 多机数据库 → 独立功能。  
实际学习时把“多机数据库”（复制、Sentinel、集群）挪到最后集中攻坚，因为它概念密度最高、前后依赖最强；独立功能（发布订阅、事务、Lua 脚本等）基本不依赖多机知识，学完单机基础后就能直接用上。  
最后补充书成书之后（Redis 2.9/3.0 以后）的现代生产内容，作为模块五。

## 各模块与工作场景的对应

| 模块 | 主要用在 |
|---|---|
| 一 数据结构与对象 | 判断每种数据类型的性能与内存占用，排查慢查询、做内存优化、理解编码转换阈值 |
| 二 单机数据库 | 持久化选型（RDB / AOF / 混合）、过期键处理、连接数治理、容量规划与故障排查 |
| 三 独立功能 | 事务与 Lua 脚本实现原子逻辑，慢查询日志排障，MONITOR 仅限临时调试 |
| 四 多机数据库 | 高可用与水平扩展架构设计，异步复制带来的一致性窗口是上层设计必须正视的边界 |
| 五 现代补充 | 内存淘汰、大 key/热 key、缓存穿透击穿雪崩、客户端选型、分布式锁正确性等日常踩坑最密集的部分 |
